Abul Research AI

An offline-first AI research assistant for Android, designed to provide private, on-device research without requiring an internet connection during use.

Vision

Help users explain, compare, analyze, and synthesize information using AI running locally on their Android devices.

Core Goals

- Fully offline operation after initial installation and setup.
- On-device AI inference using a suitable local language model.
- Local knowledge retrieval for more useful research.
- No remote AI APIs or network requests during normal use.
- No Google Play Services dependency for core offline functionality.
- Target a maximum of 12 GB RAM and 50 GB total storage.
- Public source code and reproducible build instructions.

Development Roadmap

1. Set up the Android application structure.
2. Build the initial user interface.
3. Integrate a compatible on-device AI model.
4. Implement local document retrieval and research.
5. Verify offline behavior and resource usage on a real device.
6. Publish installation and reproduction instructions.

Privacy

The project is designed to process research queries locally. Offline operation and the absence of network requests must be verified through testing before being claimed as complete.

Project Status

Early development. Core AI inference, research retrieval, and real-device testing have not yet been verified.
